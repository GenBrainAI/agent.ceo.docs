# agent.ceo Documentation

Platform documentation for [agent.ceo](https://agent.ceo) — the cyborgenic AI agent orchestration platform by GenBrain AI.

## Development

```bash
pip install mkdocs-material
mkdocs serve
```

## Deployment

```bash
mkdocs build
# Deploy to docs.agent.ceo
```

## Structure

- `docs/getting-started/` — Quick start guides
- `docs/concepts/` — Core platform concepts
- `docs/platform/` — Platform architecture and APIs
- `docs/agents/` — Agent creation and management
- `docs/features/` — Platform features
- `docs/deployment/` — Deployment guides
- `docs/integrations/` — Third-party integrations
- `docs/security/` — Security documentation
- `docs/api-reference/` — Full API reference
- `docs/guides/` — How-to guides and best practices
